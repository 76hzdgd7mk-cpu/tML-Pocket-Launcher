# 安装使用指南

## 设备与资源

- Android 9 / API 28 或更高版本，arm64-v8a。暂不提供 armv7 或 x86 APK。
- 合法拥有的 Terraria 游戏资源。
- 足够的可用存储：安装过程中需要同时容纳下载包、暂存文件、安装目录和用户数据，实际用量随版本和模组变化。
- 稳定网络用于官方版本下载、商店登录和 Steam 所有权验证。

目前有真机主菜单验证记录的组合为 Terraria `1.4.4.9` + tML `2026.09.3.1`。不承诺所有 tML 版本与所有模组均可运行。

## 1. 安装启动器

使用自行构建或项目发布的 APK。开发调试构建的路径为 `android/app/build/outputs/apk/debug/app-arm64-v8a-debug.apk`。当前应用 ID 为 `app.com.tmlpocket`，外部应用专属目录为 `Android/data/app.com.tmlpocket/`。同应用 ID 和兼容签名的覆盖安装通常保留应用数据；更换签名或卸载前请先备份。

旧模板包名 `com.example.fnatemplate` 与当前版本属于两个独立应用，安装新版不会自动迁移旧版的游戏资源、存档、模组或设置。完成备份和迁移前请保留旧版。

## 2. 添加 Terraria

在“游戏”页选择导入或商店账号入口：

| 来源            | 操作与启动要求                                                                   |
| --------------- | -------------------------------------------------------------------------------- |
| Steam ZIP       | 导入完整资源包；每次启动前登录并验证当前账号拥有 Terraria                        |
| Steam 下载      | 使用 SteamKit2 登录，根据需要在设备输入 Steam Guard 验证码，通过所有权验证后下载 |
| GOG Linux `.sh` | 导入 Linux 安装包并提取其中资源；不执行安装脚本，启动无需 GOG 登录               |
| GOG 下载        | 在官方授权页面登录，选择资源版本并下载；完整付费传输仍待真实账号验证             |

使用启动器自带的文件浏览器选取本地包，按提示授予文件访问权限。不要将存档、单独的模组包或源码压缩包当作 Terraria 资源导入。GOG 分卷包暂不支持。

## 3. 安装 tModLoader

首次打开启动器时会自动离线安装内置的 tModLoader `2026.09.3.1`。要添加其他版本，可从 tML 版本列表下载官方发行版，或导入其完整 ZIP。

不同 tModLoader 版本独立安装，成功安装后会设为当前启动版本；重新安装相同版本只替换该版本的发行文件。在「游戏 → 已安装」或底部版本选择器中，可设定启动版本、卸载指定版本。卸载当前版本时自动选择另一个可用版本；没有可用版本时需重新安装。旧版单版本安装会自动出现在列表中，无需重新导入。

存档、模组和配置保存在共用的 `userdata/`，Terraria 资源也由各版本共用，卸载 tML 版本不会删除它们。切换前请确认模组适配目标 tML 版本。取消、失败或中断的安装与卸载会通过事务恢复上一次已提交的状态。

## 4. 管理模组

“模组”页顶部统一提供 `.tmod` 导入入口。已安装列表支持搜索、启停、删除和批量操作。启用检查依赖，停用会处理依赖它的模组；更改在下次启动游戏后生效。

启动器随游戏加载 MobileJoystick 触控补丁。升级后，旧触控模组文件会移到 `userdata/Mods/.launcher-backup`，原配置可由补丁和启动器继续读取。

“下载模组”打开独立的 Terraria 与 tModLoader 创意工坊目录，可搜索、按分类和排序浏览、查看详情并下载。tModLoader 支持官方模组分类、版本和语言标签筛选；Terraria 支持世界与资源包标签。已登录时复用启动器的 Steam 会话，未登录时尝试匿名访问；单个项目可能受 Steam 权限限制。下载后启动器会校验并安装支持的模组、世界或资源包。真实设备上的工坊传输仍待验证。模组包 JSON 保存启用清单，不能代替缺失的 `.tmod` 文件。

## 5. 启动与触控

在“设置 → 控制管理”打开全屏编辑器。悬浮菜单可切换游戏控制和游戏界面。点击画布上的控件或界面区域可编辑属性，拖动可调整位置。保存后，下次启动游戏时应用布局。编辑器和游戏使用横屏，退出编辑后恢复启动器的方向设置。

渲染缩放、帧率显示和可选补丁可在设置／补丁页调整。120 FPS 与实验性托管默认关闭，不保证持续帧率或实际联机效果。

## 数据与备份

应用私有目录中的 `userdata/` 保存存档、模组和游戏配置；它与可替换的 `games/` 安装目录分离。覆盖升级前建议自行导出或复制重要数据。清除应用数据和卸载会删除私有目录，不能把这些操作作为常规修复步骤。

请不要把存档或游戏资源发到公开 Issue。反馈时提供复现步骤和已脱敏日志即可。更多问题见 [故障排查](troubleshooting.md)。
