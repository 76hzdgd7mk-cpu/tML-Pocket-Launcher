# 安装使用指南

## 设备与资源

- Android 9 / API 28 或更高版本，arm64-v8a。暂不提供 armv7 或 x86 APK。
- 合法拥有的 Terraria 游戏资源和完整的预编译 tModLoader 发行包。
- 足够的可用存储：安装过程中需要同时容纳下载包、暂存文件、安装目录和用户数据，实际用量随版本和模组变化。
- 稳定网络用于官方版本下载、商店登录和 Steam 所有权验证。

目前有真机主菜单验证记录的组合为 Terraria `1.4.4.9` + tML `2026.09.3.1`。不承诺所有 tML 版本与所有模组均可运行。

## 1. 安装启动器

使用自行构建或项目发布的 APK。开发调试构建的路径为 `android/app/build/outputs/apk/debug/app-arm64-v8a-debug.apk`。同应用 ID 和兼容签名的覆盖安装通常保留应用数据；更换签名或卸载前请先备份。当前应用 ID 为 `com.example.fnatemplate`，用于保留既有安装身份。

## 2. 添加 Terraria

在“游戏”页选择导入或商店账号入口：

| 来源            | 操作与启动要求                                                                   |
| --------------- | -------------------------------------------------------------------------------- |
| Steam ZIP       | 导入完整资源包；每次启动前登录并验证当前账号拥有 Terraria                        |
| Steam 下载      | 使用 SteamKit2 登录，根据需要在设备输入 Steam Guard 验证码，通过所有权验证后下载 |
| GOG Linux `.sh` | 导入 Linux 安装包并提取其中资源；不执行安装脚本，启动无需 GOG 登录               |
| GOG 下载        | 在官方授权页面登录，选择资源版本并下载；完整付费传输仍待真实账号验证             |

使用启动器自带的文件浏览器选取本地包，按提示授予文件访问权限。不要将存档、单独的模组包或源码压缩包当作 Terraria 资源导入。GOG 分卷包暂不支持。

## 3. 安装 tModLoader

打开 tML 版本列表，选择官方 GitHub 发行版，或导入其完整 ZIP。需要游戏 DLL、依赖清单、运行时配置、FNA 和发行 Content；GitHub 自动生成的 Source code ZIP 与单个 DLL 都不够。

当前仅管理一个活动发行版。安装另一版本会替换发行文件，用户存档、模组和配置保存在独立目录。取消或失败的安装应保留上一次有效安装。

## 4. 管理模组

“模组”页顶部统一提供 `.tmod` 导入入口。已安装列表支持搜索、启停、删除和批量操作。启用检查依赖，停用会处理依赖它的模组；更改在下次启动游戏后生效。

内置 MobileJoystick 由启动器维护、保持启用，不提供普通模组的删除开关。它的设置和其他模组配置在更新时保留。

“下载模组”可打开官方工坊、按项目编号查询公开信息并获取开放 CDN 文件。需要认证 UGC 通道的项目请先通过 Steam 获得 `.tmod` 后导入。模组包 JSON 保存启用清单，不能代替缺失的 `.tmod` 文件。

## 5. 启动与触控

确认环境就绪后点击“启动游戏”。启动界面显示阶段与状态，失败时可查看日志。游戏内进入 MobileJoystick 设置调整按键布局、大小和透明度。启动器默认横屏，可在设置中切换竖屏；游戏保持横屏。

渲染缩放、帧率显示和可选补丁可在设置／补丁页调整。120 FPS 与实验性托管默认关闭，不保证持续帧率或实际联机效果。

## 数据与备份

应用私有目录中的 `userdata/` 保存存档、模组和游戏配置；它与可替换的 `games/` 安装目录分离。覆盖升级前建议自行导出或复制重要数据。清除应用数据和卸载会删除私有目录，不能把这些操作作为常规修复步骤。

请不要把存档或游戏资源发到公开 Issue。反馈时提供复现步骤和已脱敏日志即可。更多问题见 [故障排查](troubleshooting.md)。
