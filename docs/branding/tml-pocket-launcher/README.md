# tML Pocket Launcher · 像素图标提案

设计目标：名称指向 tModLoader 手机启动器；图形体现 Pocket 的随身口袋、Launcher 的启动动作及 Terraria 的像素世界。图标不放完整产品名，避免手机桌面缩小时文字不可读。

主推 **01 口袋世界**：草绿口袋边缘、青绿袋身与浅色像素启动符号。使用 4 单位像素网格，深色底，不使用模糊、渐变或玻璃效果。玻璃质感留在启动器界面，品牌轮廓保持清晰。

| 方案          | 设计取向                             |
| ------------- | ------------------------------------ |
| 01 口袋世界   | 草地方块、口袋和启动符号，最贴合名称 |
| 02 像素 P     | Pocket 的首字母，适合简洁工具品牌    |
| 03 随身树苗   | 树苗从口袋生长，突出自然与探索       |
| 04 模组拼片   | 拼片与启动键结合，突出模组组合       |
| 05 像素传送门 | 跨入游戏世界，紫绿配色强调冒险       |
| 06 口袋模组箱 | 像素收纳箱，突出版本与模组管理       |

## 文件

- `index.html`：离线交互展示页，支持浅色背景、圆形裁切、单色对比和方案选择。
- `concept-sheet.png`：六款方案总览。
- `concepts/*.svg`：方形底图版本；文件名以 `-mark.svg` 结尾的是透明图形版本。
- `exports/`：六款 1024px PNG。主推款另含 512、192、96、48、32px 及透明 PNG。

通过 `node scripts/design/generate-branding.cjs` 重新生成；需要已有的 UI Playwright 依赖及 Edge。SVG 为直接编写的原创像素矢量，PNG 通过浏览器确定性渲染，没有调用付费图像 API。

工作流程参考用户指定的 [logo-generator 技能](https://github.com/op7418/logo-generator-skill/blob/main/SKILL.md)及其设计模式和展示页模板；展示页针对像素图标重写为离线版本。图形不复制 Terraria 或 tModLoader 的现有标志。目前是设计提案，尚未替换应用桌面图标。
